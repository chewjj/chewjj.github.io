## 13. Global constraints

The site should:
- be responsive;
- use semantic, understandable HTML;
- keep CSS readable;
- use minimal JavaScript;
- use no framework unless there is a clear reason;
- use no more than 2 typefaces;
- use no more than 1 accent colour;
- have clear visual hierarchy;
- use whitespace deliberately;
- treat imagery deliberately;
- remain understandable enough for me to edit.

---

## 14. Avoid by default

Unless my references clearly justify them, avoid:
- generic gradient hero backgrounds;
- glassmorphism;
- rows of floating rounded cards;
- excessive rounded corners;
- generic "Hi, I'm X" hero copy;
- random animated particles;
- meaningless progress bars;
- fake testimonials;
- decorative icons beside every heading;
- excessive pill-shaped UI;
- generic SaaS/startup visual language;
- animation without a design purpose.
